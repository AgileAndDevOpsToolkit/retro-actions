Catalogue d'actions de rétro

Impossible de charger les données

Le fichier actions-retro.json doit se trouver dans le même dossier que cette page, et la page doit être servie par un serveur web (le navigateur bloque la lecture d'un fichier local ouvert en file://). En local : python3 -m http.server dans le dossier, puis http://localhost:8000/catalogue-actions-retro.html.

Choisissez le périmètre concerné par l'action d'amélioration.
